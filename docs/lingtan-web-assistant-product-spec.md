# 灵碳助手 Web · 产品功能说明（现状基线）

本文档描述 **当前已实现、可验收的端上行为**（界面 + 与 API Server 的真实交互），用于产品/交付对齐。  
与「演示脚本」区分：凡未在界面闭环内完成用户目标的，列入 **§7 非本次交付 / 已知缺口**，不包装为正式功能。

**适用入口**：`ui-cloud-local`（灵碳助手 Web 壳层），依赖同源或可访问的 Hermes **API Server**（OpenAI 兼容路径 + 灵探账号与同步扩展路由）。

---

## 1. 产品定位（一句话）

登录后的 **端云一体工作台**：在同一账号下浏览本机 Hermes **Skills / 可委派 Agents 配置**，进行 **可持续多轮对话**（服务端 SessionDB），并具备 **设备绑定 + 同步事件推拉** 的基础能力。

---

## 2. 用户动线

1. **访客**：落地页邮箱 + 密码 → 注册（可选）→ 登录。
2. **登录后**：进入主壳（左侧导航 + 主内容区），默认展示 **Skills**；可切换 **Agents · 智能助手 · 云端同步 · 账号中心**。
3. **使用智能助手**：系统自动对齐 **账号默认主会话**（或用户主动进入 **分支会话**），加载历史后收发消息；可选开启 **子代理模式** 影响后续模型请求策略。
4. **需要同步时**：在账号中心 **绑定设备**，在云端同步页 **推送样例 / 拉取事件**（见 §4.4）。
5. **退出**：清除本机登录态与缓存键，回到落地页（见 §7：服务端吊销见缺口说明）。

---

## 3. 信息架构（导航与模块）

| 模块 | 产品职责 | 后端主要依赖 |
|------|----------|----------------|
| **Skills** | 展示当前运行环境可发现的 Skill 目录（名称、描述、分类、是否在配置中停用） | `GET /v1/assistant/skills` |
| **Agents** | 展示 `lingtan_ui.agents` 中已启用的 **子代理专员档案**（非运行时任务看板）：id、名称、说明、声明的 toolsets | `GET /v1/assistant/agents` |
| **智能助手** | 与 Hermes 后端多轮对话；主会话按账号稳定；支持临时「新建对话」分支；可选子代理委派模式 | `GET /v1/assistant/chat-session/default`、`GET /v1/assistant/conversation`、`POST /v1/chat/completions` + 头参见 §4.3 |
| **云端同步** | 在已绑定设备前提下，向云端推送一条结构化样例事件；或按游标增量拉取事件 | `POST /v1/sync/push`、`GET /v1/sync/pull` |
| **账号中心** | 表单注册/登录（与落地页登录并存）、绑定 Web 端设备、原始 JSON 结果展示 | `POST /v1/auth/register`、`POST /v1/auth/login`、`POST /v1/devices/register` |

**侧栏展示项说明（产品诚实项）**：

- 「搜索任务」「+ 新建任务」以及 **写死的工作空间名称列表** 在当前实现中 **仅为壳层占位，不产生业务请求**，不计入已交付功能。

## 4. 功能规格（可验收）

### 4.1 认证与账号

- **注册**：邮箱 + 密码（不少于产品侧提示的位数要求），调用注册接口，结果在账号中心面板展示。
- **登录**：落地页或账号中心均可登录；成功后写入本机 **访问令牌**（`localStorage`），并自动拉取 Skills、Agents、默认会话与聊天历史。
- **鉴权方式**：受保护接口使用 `Authorization: Bearer <access_token>`；部分同步请求附加 `X-Lingtan-Device-Id`（绑定设备后）。

### 4.2 Skills 目录

- 登录后才加载；支持 **关键字筛选**（名称、描述、分类）。
- 每条展示：标题、分类标签、启用/已停用状态、描述摘要。
- **刷新** 重新从服务端拉取目录。

**产品边界**：目录来自服务端 Hermes 环境的 Skill 发现逻辑；**不提供**在 Web 内启用/停用 Skill 的配置编辑（需运维在 `config.yaml` 等侧处理）。

### 4.3 智能助手（对话）

**会话模型（产品语义）**

- **主会话**：与 **灵探账号绑定** 的默认 Hermes SessionDB 线程；换浏览器或清理部分本地数据后，同一账号仍回到 **同一条主会话**（由服务端提供稳定 `session_id`）。
- **分支会话**：用户点击「新建对话」后进入 **仅此浏览器有效的** 临时会话（`web-*`），便于并行话题；「返回主会话」放弃分支，回到账号默认主会话并重新加载主会话历史。

**关键行为**

- 进入对话区或发送消息前，客户端会 **校准当前应使用的 Hermes `session_id`**（主会话由服务端下发，分支会话本地生成）。
- 拉取历史：`GET /v1/assistant/conversation?session_id=…`。
- 发送消息：`POST /v1/chat/completions`，**非流式**；请求携带 `X-Hermes-Session-Id`，保证多轮在 SessionDB 延续。
- **子代理模式**：开关持久化在本机；开启后请求携带 `X-Lingtan-Subagent: 1` 与 body `subagent: true`，服务端在当轮注入子代理编排上下文（是否实际调用 `delegate_task` 由模型决定）。

**快捷入口**：三条预设提示可一键填入并发送（数据分析 / 项目管理 / 同步总结）。

**产品边界**

- 历史展示以 **用户/助手文本** 为主；对无正文的助手消息或 tool 类消息可能简化或省略，不与完整 Hermes 会话检查器 1:1 对齐。
- **不支持**在 Web 内的流式打字机输出（当前为整段返回）。

### 4.4 设备与同步

- **绑定设备**：为当前 Web 环境登记一台逻辑设备，获得 `device_id` 并本地持久化。
- **推送样例**：构造一条符合协议字段的示例事件写入同步流（需已绑定设备）。
- **拉取事件**：按本地保存的 **游标** 增量拉取，并推进游标持久化。

## 5. 客户端状态与隐私（产品告知）

以下键用于恢复体验，均存于浏览器 **localStorage**（用户清除站点数据会丢失除「主会话 id 可由服务端再次下发」之外的本地偏好）：

| 键 | 含义 |
|----|------|
| `wb_access_token` | 访问令牌 |
| `wb_device_id` | 已绑定设备 |
| `wb_sync_cursor` | 同步拉取游标 |
| `wb_hermes_session_id` | 当前使用的 Hermes 会话 id（主会话或分支） |
| `wb_chat_fork` | 是否处于「分支会话」模式 |
| `wb_subagent` | 子代理模式开关 |

---

## 6. 能力与发现

客户端可通过 `GET /v1/capabilities` 获知服务端声明的能力（含会话续写头、子代理相关头/字段、灵探同步与 Assistant 目录路由等）。产品迭代时以该端点 + 本文档 **双源** 对齐。

---

## 7. 非本次交付 / 已知缺口（不按正式功能承诺）

以下项 **后端可能已有接口或壳层已占位**，但 **未在 Web 产品闭环内完成**，验收时不应计为「灵碳助手 Web 已交付」：

- **访问令牌刷新**：未持久化或使用 `refresh_token`，Access 过期后需用户重新登录。
- **服务端登出/吊销**：退出仅清理本机，不调用的服务端吊销接口（若部署要求单点失效，需补全）。
- **任务中心**：侧栏「搜索任务」「新建任务」无真实任务 CRUD。
- **工作空间切换**：侧栏工作空间为静态展示，无切换逻辑与数据隔离。
- **流式回复、富文本、工具调用时间线、会话列表管理、多 Tab 会话管理** 等均未作为当前 Web 规格交付。
- **PRD 中的采集器、报告中心、任务编排全链路** 不在本文档 Web 范围内（见 `docs/cloud-local-sync-prd.md` 与实现阶段计划）。
